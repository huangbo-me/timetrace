# 时光落点 · TimeTrace

> 到达即记录，离开即结束。

时光落点是一款以地点为线索的 iPhone 时间记录应用。为常去的工作地点、图书馆、健身房等设置地点围栏后，进入地点会自动开始记录，离开后自动结束；也可以随时手动补录与修正。

它只关心你是否进出已设置的地点边界，不保存连续移动轨迹。

## 功能

- 自动记录：基于 Core Location 地点围栏，在到达与离开已启用地点时记录活动时段，并提供进入、离开通知。
- 多地点管理：可添加、编辑、启用、停用和删除地点，设置地点名称、类型与围栏半径；地图支持查看全部地点或回到当前位置。
- 手动补录与修正：支持新增、编辑、删除记录；对缺少开始或结束事件的异常记录提供补齐或忽略操作，原始事件会保留。
- 今天与历史：展示当前进行中的记录、日汇总、待补齐记录以及最近六个月的历史。
- 正常工时与加班：工作地点支持中国大陆法定工作日或自定义每周工作日，支持固定上下班与弹性工时，并可设置休息时长；历史展示相应的正常工时和加班分类。
- 统计分析：每日一句贴近近期记录的关照；按今天、近三天、本周、上一周、最近 30 天或自定义日期及地点类型查看洞见，点击主卡追溯记录，下方保留时长、趋势和详细统计。
- 活动提醒：设置 → 活动提醒 → 管理提醒支持新增、编辑名称 / 时间 / 重复日期、启停和删除。通知中可开始、延后或跳过，开始后在今天页完成活动；权限不足时可前往系统设置。
- 关于应用：设置 → 关于时光落点展示应用介绍、当前安装包的版本号与构建号，以及反馈邮箱；可一键复制版本信息用于反馈。
- iCloud 同步：存储初始化时 iCloud 可用则接入私有 CloudKit，保存活动、地点、事件、会话、提醒定义和提醒实例；设置页显示账户与存储配置状态，不代表每条数据都已同步完成。
- 文件备份：设置 → 数据备份可导出密码加密文件并导入合并；相同 UUID 保留本机版本，导入后会重放事件更新会话。昵称和系统权限不包含在备份中。
- 中文体验：当前界面与日期、时长格式均面向简体中文。

## 工作安排与历史加班

新工作地点默认使用中国大陆法定工作日、固定上下班 09:00–18:00、休息 0 小时。离线节假日与调休表只覆盖 2026 年，其他年份按周一至周五工作、周末休息计算，不读取系统日历。切换“自定义每周工作日”后可选择通常上班的星期。

固定上下班支持跨午夜，班次归属开始日；工作日班次从正常工时扣一次休息，不抵消早到或晚走。弹性工时按会话所在时区的自然日计算，正常工作日扣除休息后，超过每日标准工时的部分显示为“工作日加班”。标准工时可选 0.5–16 小时，休息可选 0–12 小时，均按 0.5 小时递增。休息日不扣休息，除归属前一工作日夜班的部分外，在岗时间全部计为休息日加班；这些分类不涉及薪资倍率。

例如 2026 年 9 月 21 日 10:00–21:00，在法定工作日、弹性标准 8 小时、休息 3 小时下，正常工时为 8 小时、加班为 0。旧记录与旧备份缺少新字段时，继续采用自定义星期、固定上下班、零休息的兼容口径，不会因升级静默改变历史。

修改排班后，居中弹窗显示当前地点 N 条未删除记录（包含进行中，排除其他地点）：“仅今后”保留这 N 条记录的原排班，下次到达生效；“全部历史（N 条）”按新排班重算；也可取消。数量在点击保存时捕获，“仅今后”为旧记录补写旧快照不代表已有统计改变。

历史页每次更新统一生成来源、加班和跨天结果，来源事件预先索引，卡片复用结果；两列瀑布流依据时段数量、跨天和加班附加行估算高度分配，保留分页和类型筛选，减少末尾单侧长空白。

## 隐私

- 不收集连续位置轨迹，只记录已设置地点的进入与离开事件。
- 数据默认保存在设备本机。
- 启用 iCloud 后，业务记录同步到用户自己的私有 CloudKit 数据库，开发者无法读取该数据库。
- 设置 → 外观通过卡片内直接点选（无弹出菜单）提供暖砂、森林、晴空、暮紫、蔷薇五套全局主题，以及跟随系统、浅色、深色显示模式；选择保存在本机，即时应用于页面、卡片与控件；“桌面图标跟随主题”默认关闭，开启时立即同步当前主题的图标，之后点选主题也会更换图标；系统会显示更换提示，失败可重试。关闭开关保留当前桌面图标。仅切换浅色/深色显示模式不会更换图标。分享图片使用所选主题的浅色配色。
- 统计页的智能文案使用 CloudKit 用户标识鉴权，只上传去标识化汇总和事实指纹，不上传地点、坐标或原始记录。每日关照按账户、时区、日期保存在本机，来源修改或删除后失效；周期洞见与当前事实不匹配时回退本地表达。接口新增字段缺失时仍可使用页面，时间与类型筛选合并为单行下拉入口，自定义日期在弹层选择。分享海报复用当前洞见卡片及点击时的文案和数据快照，以 9:16（1080×1920）图片导出，默认隐藏具体地点名称，附带时光落点 App Store 下载二维码。新增智能关照和洞见需服务端配合，详见 [每日关照与洞见接口约定](INSIGHT_CARE_API.md)。
- 地点围栏、通知调度属于设备运行时状态：CloudKit 同步记录后，App 会在每台设备上重新注册围栏和提醒。

完整隐私说明见 [隐私政策](AppStoreAssets/PRIVACY_POLICY.md)。

## 技术概览

| 层次 | 采用方案 |
| --- | --- |
| UI | SwiftUI、Swift Charts、MapKit |
| 数据 | SwiftData；可用时同步至私有 CloudKit（`iCloud.com.chronora.time.trace`） |
| 自动记录 | Core Location `CLCircularRegion` 地点围栏 |
| 通知 | UserNotifications 本地通知 |
| 记录模型 | 先追加事件，再确定性重放为会话，最后生成统计 |
| 测试 | XCTest 单元测试 |

核心数据流为：

```text
地点围栏 / 本地通知 / 手动操作
              ↓
        ActivityEvent（只追加）
              ↓
   ActivitySessionEngine（重放）
              ↓
      ActivitySession（记录时段）
              ↓
      AnalyticsService（统计）
```

项目保持单一 App Target 和单一 Test Target，不依赖第三方库。目录与领域约定可参阅 [当前架构](CURRENT_ARCHITECTURE.md) 与 [领域词汇](CONTEXT.md)。

## 本地运行

### 环境

- macOS 与 Xcode（项目当前部署目标为 iOS 26）
- iPhone 或 iOS 模拟器
- 真机自动记录需要定位权限；后台围栏、通知送达和跨设备 iCloud 同步需要在真机验证

### 步骤

1. 使用 Xcode 打开 `TimeTrace.xcodeproj`。
2. 在 Signing & Capabilities 中选择你的开发团队；如需验证 iCloud，同步配置 CloudKit 容器与签名能力。
3. 选择 iPhone 模拟器或已连接的 iPhone，运行 `TimeTrace` scheme。
4. 空库且 iCloud 可用时，先选择恢复已有数据或开启新记录；随后完成地点设置并允许定位。后台自动记录需要真机的“始终允许”定位权限。删除最后一个地点后仍可访问历史，后续添加地点会复用默认工作活动。

也可以在仓库根目录构建：

```bash
DEVELOPER_DIR=/Applications/Xcode.app/Contents/Developer \
xcodebuild -project TimeTrace.xcodeproj -scheme TimeTrace \
  -destination 'generic/platform=iOS Simulator' build
```

模拟器适合验证界面与单元测试，但不能证明真实的后台围栏唤醒、系统通知送达或跨设备 CloudKit 恢复。

## 调试数据

仅在 Debug 构建中，设置页可开启“测试数据工具”，生成或清除 30 天全场景演示数据。该入口经过编译条件保护，不会出现在正式发布版本中。

## 当前边界

- 当前产品界面以“工作”作为默认活动视角；底层模型已支持活动、地点、事件、会话和提醒的通用建模，完整的活动切换界面仍待完善。
- 提醒使用系统重复本地通知；每次可观测投递按请求标识与投递时间独立建实例。后台送达且无人操作时，不保证收到应用回调；滚动预排程尚未实现。
- `ChinaWorkCalendar` 只内置 2026 年节假日与调休表；其他年份采用普通周末判断。地点的工作日规则、工时模式和休息时长用于本机正常工时与加班统计，不限制围栏实际记录。
- 手机只读导出的源记录可用于核对预期，但不会改变已安装旧版本的统计结果；9 月 21 日的实际手机重算与真实数据滚动表现仍待安装新构建后验收。
- 今天页主卡随当前进行中地点的类型切换累计时长；进行中的工作或居住围栏会话从原始到达时间连续计时并显示完整到达日期，结束后恢复当天累计口径。主卡与今日时间线按各自关联地点使用统一类型图标，无当前地点或关联地点缺失时显示中性定位图标；无进行中地点时显示工作地点及无地点手动会话的今日工作时长，汇总所有工作活动下的记录。历史日汇总仍将整段会话归属开始日，重叠地点时长不去重。统计的全部地点视角使用停留时长等中性文案，单地点视角按地点类型展示。
- 账户检查及有限次数刷新不代表 CloudKit 全部恢复完成；没有每次云合并的实时监听。登录状态改变后需重启应用以重建存储配置。
